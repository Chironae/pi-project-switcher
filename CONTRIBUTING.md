# Contributing to Pi Project Switcher

Thank you for considering contributing to this project.

## How to Contribute
- Fork this repository.
- Create a new branch for your feature or fix.
- Commit your changes with clear messages.
- Open a pull request with a description of your changes.

## Coding Guidelines
- Keep scripts simple and portable.
- Follow existing file structure and naming conventions.
- Avoid hardcoding user-specific paths or values.
- Test your changes in a sandbox project context before submitting.

## Feature Requests & Issues
- Open an issue to suggest enhancements or report bugs.
- Be clear and specific about the desired behavior or problem.

## Code of Conduct
- Be respectful.
- Be constructive.
- Be open to feedback.

Thank you for helping improve Pi Project Switcher!
